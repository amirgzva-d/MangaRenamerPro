# Manga Renamer Pro

اپلیکیشن اندرویدی فارسی برای مدیریت کتابخانه مانگا و تغییر نام امن فایل‌ها.

## قابلیت‌های موجود در نسخه اولیه

- انتخاب پوشه با مجوز رسمی Android Storage Access Framework و نگهداری دسترسی
- نمایش پوشه‌ها و فایل‌ها؛ شناسایی پسوندهای تصویری، PDF، CBZ/CBR، ZIP، RAR، 7Z و EPUB
- نمایش شبکه‌ای ۱ تا ۴ ستونه و جلد تصویری پوشه‌ها
- علاقه‌مندی، مخفی‌سازی و سنجاق پوشه‌ها
- نمایش تعداد موارد و ادامه مطالعه از آخرین صفحه
- مطالعه تصاویر داخل پوشه با ذخیره صفحه فعلی و نوار پیشرفت
- بازکردن PDF و آرشیوها با برنامه مطالعه نصب‌شده در دستگاه
- انتخاب و پخش موسیقی پس‌زمینه
- رابط فارسی راست‌چین با تم سبز تیره

## دو روش تغییر نام

### ۱. حفظ شماره موجود
اگر نام فایل دقیقاً یک عدد داشته باشد و پرانتز نداشته باشد، همان شماره حفظ می‌شود و متن ابتدای نام قابل تنظیم است. اگر چند عدد، پرانتز یا وضعیت مبهم وجود داشته باشد، برنامه آن را خودکار تغییر نمی‌دهد و بررسی دستی می‌خواهد.

### ۲. متن ثابت دلخواه
متن ثابت را می‌توان روشن یا خاموش کرد. شماره فایل به‌صورت خودکار تشخیص داده می‌شود؛ فقط برای فایل‌های مبهم، شماره همان فایل را دستی وارد می‌کنید.

قبل از اجرا پیش‌نمایش ساخته می‌شود. برنامه موارد مبهم و نام‌های تکراری را هشدار می‌دهد و شماره فایل‌ها را جابه‌جا نمی‌کند.

## دریافت APK

1. وارد تب **Actions** مخزن شوید.
2. آخرین اجرای موفق **Build Android APK** را باز کنید.
3. از بخش **Artifacts** فایل `MangaRenamerPro-Android-APK` را دریافت کنید.
4. ZIP را استخراج و APK را روی گوشی اندرویدی نصب کنید. ممکن است لازم باشد اجازه نصب از این منبع را در Android فعال کنید.

با Push تگ نسخه‌ای مانند `v1.0.0`، فایل APK در GitHub Releases نیز منتشر می‌شود.

## ساخت دستی

نیازمند JDK 17، Android SDK و Gradle 8.9:

```bash
gradle assembleDebug
```

خروجی:
```
app/build/outputs/apk/debug/app-debug.apk
```

## محدودیت‌های فعلی

- فایل‌های تصویری داخل پوشه در مطالعه‌گر داخلی نمایش داده می‌شوند.
- PDF و فرمت‌های آرشیو فعلاً به برنامه سازگار نصب‌شده روی گوشی سپرده می‌شوند.
- پشتیبانی داخلی از استخراج CBZ/CBR، مدیریت پیشرفته جلد، Undo تاریخچه تغییر نام و تست روی دستگاه واقعی هنوز نیازمند تکمیل است.
